# ADR 03 Arch Linux ARm

Date: *17:08:2026*

## Reasons
The reasons Arch Linux Arm has been chosed as the base are:
- Endeavour OS was not working on rpi5.
- It has wide support
- It is highly customizable in configuration.
- It has all latest packages.
## Consequences
CrossOS has been stuck in a phase of hopping bases and that will continue until Arch Linux is installed.

### Advantages
- Highly customizable
- Standard for most distributions
- Best package support
### Disadvantages
- Hard to install.
- Requires entensive setup to work.
